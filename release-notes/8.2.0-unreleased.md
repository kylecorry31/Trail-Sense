# 8.2.0 Release Notes

This contains a list of the changes in Trail Sense 8.2.0.

## Field Guide

### Multiple Images for a Page
You can now attach multiple images to a field guide page. Use the arrows or swipe to view them. The default page can be set using the menu button on the image while editing the page.

### Color Sighting Markers on Map Layer Based on Classification
By default the Sightings map layer will change the color of the sighting markers based on the classification (ex. plant vs fungus). This is available as a layer setting if you want to turn it off or switch to it instead of the sighting images.

### Scientific Names

### Minor Changes
- The open button on the map layer and record sighting snackbar now opens the sighting you clicked on rather than the field guide page
- When a sighting is opened, clicking back will always bring you through the sighting list and field guide page before returning to where you came from
- The field guide page name is now shown on the sightings list and entry page
- You can now delete a sighting from the entry page
- You can now hide built-in pages

## Miscellaneous

### Minor Changes
- Added notification channel groups in the system notification settings page
- Displayed clock offset from system time in the Clock tool (thanks to @arpitagarwal1301 for the contribution)
- Increased font size of the location sheet in the Navigation tool (thanks to @arpitagarwal1301 for the contribution)
- Added distance and direction to the selected point sheet on the map (thanks to @Maqbool61 for the contribution)
- Added diagnostics for when an alarm notification channel is blocked
- Added a button in the Diagnostics tool to export logs to a zip file
- Added messaging on the Signal Finder tool for when the location permission is denied
- Improved map tile memory usage
- Improved messaging when an offline map fails to import
- Changed the "unknown" sensor status badge color to gray
- Added a setting to adjust the navigation bearing length (thanks to @Maqbool61 for the contribution)
- Added the ability to export trail maps (thanks to @Maqbool61 for the contribution)
- Country and state/province boundaries are now visible on trail maps (if available in the .map file)
- Cell signals are now sorted by full service first and then signal strength
- The recommended apps user guide page was moved to GitHub (https://github.com/kylecorry31/Trail-Sense/discussions/4002)
- Added angle text for the center bubble level (thanks to @darrencoen for the contribution)
- Reduced sensor update frequencies on some tools
- Enabled text suggestions and capitalization in text inputs across the app
- Translation updates. Thank you to all the translators!
