# 8.1.1 Release Notes

This contains a list of the changes in Trail Sense 8.1.1.

See the [8.1.0](./8.1.0.md) release notes.

## Bug Fixes
- Fixed an application-not-responding (ANR) crash while panning/zooming the map.
- Fixed a crash in the Weather tool when a sequence of very noisy weather readings is present.
- Fixed a crash when using the settings quick action from augmented reality and returning to the previous screen.
- Fixed tool search for Chinese and other non-Latin locales.
- Fixed a crash when calculating a lunar eclipse whose end occurs shortly before moonrise.
- Reduce map tile cache size when high detail mode is off.
- Reduce memory footprint of map tiles while filling in borders.
