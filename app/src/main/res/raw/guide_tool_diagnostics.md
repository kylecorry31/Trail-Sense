Use the Diagnostics tool to detect common issues that affect the tools in Trail Sense. If you have a problem with the app, run the Diagnostics tool to check whether it can find the cause.

## Review and fix issues
Trail Sense lists the warnings and errors it detects. Warnings have a yellow icon, and errors have a red icon.

To see more information about an issue and how to resolve it, tap the item. The dialog lists the affected tools and the steps to resolve the issue, and has a **Settings** button that opens the matching settings.

To see the readings from your sensors, tap the sensor icon in the top-right corner.

The Diagnostics tool can detect the following issues:

- Poor sensor accuracy
- Missing sensors
- Missing permissions, including the background location permission
- Blocked notifications
- Accidental location or altitude overrides
- Restricted background access
- Power saving mode being on
- Missing alarms and reminders permission
- System file picker lacking permission to access files
- Poor battery health
- Weather monitor turned off, on devices with a barometer
- Automatic backup folder that Trail Sense can't write to

## Export logs
To save your logs, tap **Export logs**, choose where to save the file, and tap **Save**. Trail Sense saves a ZIP file that contains the following:

- Recent crash stack traces
- Historical process exit reasons
- Trail Sense's own log file
- Recent system log output (the last hour)
