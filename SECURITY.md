# Security Policy

Trail Sense is designed to work offline and does not provide an internet-facing service. Security issues are still welcome, including issues involving local data, imported files, or interactions with other apps/plugins.

## Reporting a vulnerability

Please email [trailsense@protonmail.com](mailto:trailsense@protonmail.com) with a description of the issue, the affected app version and device/Android version, and steps to reproduce it if possible. Please avoid including personal or location data in reports.

Reports are reviewed on a best-effort basis. There is no guaranteed response time or commitment to provide a fix. If an issue is addressed, a fix will generally be included in a normal app release; out-of-cycle or security-only releases are not guaranteed. Please avoid publicly sharing vulnerability details before reporting them.
