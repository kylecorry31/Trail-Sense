Frequently Asked Questions

There is a Diagnostics tool in Trail Sense to detect common issues and offer solutions. You can access it via Trail Sense Settings > Diagnostics (user guide). If you don't see your question here, see how to get support.

Getting started

Should I rely on Trail Sense?

No. Trail Sense is a tool and you should have appropriate backups (just like any other tool). I'm the only developer and it is a hobby project (that I use), so I may get things wrong or it may have bugs. It is not a substitute for common sense or skills. Besides Trail Sense, your phone could break, run out of battery, or malfunction in some way that makes it unusable - so don't rely on a single device/tool (especially one as complex as a smartphone).

How can I install Trail Sense?

There are 3 official sources for Trail Sense:

  • GitHub (releases tab or Obtainium)
  • Google Play Store
  • F-Droid

You can find the links to these in the readme of the repository. GitHub is the preferred source since I have the most control over that and it receives the fastest updates, but all of them are valid.

If you download Trail Sense from somewhere else, then you are on your own and you should be aware that it may not work properly or contain malware.

Where can I learn how to use Trail Sense?

See the User Guide tool in app or view it on the web in the User Guide. Every tool has its own guide.

What versions of Android are supported?

Trail Sense supports Android 7.0 and newer. Support for older versions gets dropped when the libraries I depend on stop supporting them (that is why Android 6.0 is no longer supported). I only have a small selection of phones, so I mostly test on newer versions of Android.

How can I report a bug, ask a question, or request a feature?
  • Bug or question: See how to report a bug or ask a question.
  • Feature: See how to request a feature.
  • Email: trailsense@protonmail.com

For bugs, please include where you installed Trail Sense from, the version, your device and Android version, and the results of the Diagnostics tool. I only have a few phones to test with, so the more detail you can give me, the better chance I have of reproducing the issue.

When can I expect new releases?

I try to create a release every month or two, but don't have a set release schedule. Translations through Weblate get bundled into the main releases.

Does Trail Sense work on custom ROMs?

Trail Sense should work on most if not all custom ROMs. Due to the nature of custom ROM development, it may not be as stable and support may vary by manufacturer.

GrapheneOS is officially supported and has been confirmed to work well. If you see lag spikes while using the Navigation, Offline Maps, or Map tools you may want to consider disabling the "hardened memory allocator" under the system app info for Trail Sense. I'm looking to improve performance with the hardened memory allocator enabled.

Will there be an iOS version?

No - I don't have the resources or time to build and maintain an iOS version.

Will Wear OS support be added?

No - I don't have the resources or time to build and maintain a Wear OS version.

Maps

Why aren't maps visible?

Trail Sense does not include built-in street maps, satellite imagery, or trail data. It does not download maps from the internet (or have internet access). To display a map, you must import your own using the Offline Maps tool:

  • Trail maps: Import a Mapsforge (.map) file. These show up on the Map tool's trail maps layer.
  • Photo maps: Import an image or PDF. If the PDF is geospatial (ex. exported from CalTopo), Trail Sense can calibrate it automatically.

Here is a list of places to download maps, and the Offline Maps user guide explains how to import and use them. If you need live or preloaded street, satellite, or trail maps, use a dedicated mapping application instead.

I can't import a map or it crashes when I import it
  1. Make sure the file downloaded completely. If the size is smaller than what the download site lists, the file may be incomplete or corrupt - try downloading it again.
  2. Trail Sense supports Mapsforge version 3, 4, and 5 maps. If you are downloading a trail map, use the V5 version.
  3. Try copying the file to your phone's internal storage (not an SD card) and importing it from there.
  4. Try importing the small world map (a few MB). If that works, the problem is with your map file. If it doesn't, your device may be affected by a bug in Android's file picker (this mostly affects Samsung and Xiaomi devices) that I haven't been able to work around.
  5. If you are still stuck, restart your phone and try again, then let me know which device you are using and what error you see.

Weather

Why don't I see the weather tab?

In order to predict the weather, your device needs to have a barometer sensor. Not all devices have this, you can verify by using the Diagnostics tool.

The pressure graph isn't populating or is very jagged, how can I fix it?
  • If the weather monitor is off, Trail Sense only records the pressure when you open the Weather tool. Turn on the weather monitor to record it in the background (Weather tool or Settings > Weather).
  • If it is on, readings may be getting missed due to battery restrictions. You may need to mark Trail Sense as exempt from battery optimizations. See background services stop running.
  • If the graph is jagged, increase the pressure smoothing under Settings > Sensors > Barometer (about 15% is recommended). The chart on that screen shows the raw pressure (gray line) and the calibrated pressure (colored line), so you can adjust it until the colored line follows the gray line smoothly. Too much smoothing can hide real pressure changes.

See the Weather user guide for more information.

Why does Trail Sense think a storm is approaching?

Causes

  1. The pressure is falling rapidly, which is typically a sign of an approaching storm
  2. Your altitude is changing quickly (ex. driving), which appears as a rapid pressure drop

Possible solutions

  1. Lower the forecast sensitivity under Settings > Weather to make it less sensitive to pressure changes (and the storm sensitivity if you get storm alerts)
  2. Increase the pressure smoothing under Settings > Sensors > Barometer (about 15% is recommended) to reduce noise in the readings
  3. Grant Trail Sense the location permission. It uses the GPS to get your elevation, which helps it convert the pressure to sea level pressure and improves the prediction.
  4. Disable the weather monitor if you are travelling by car

The prediction is a best guess from the available sensor data, so if you see storm clouds rolling in, trust your instincts.

The temperature is inaccurate

Trail Sense can get the temperature from two sources, and neither is perfect:

  • Historic: The historical average temperature for your location (from 30 years of data) at this time of year. It is not the actual temperature, so it won't match the current weather conditions.
  • Sensor: Read from your phone's built-in thermometer. It is often inaccurate because it is affected by the heat from your phone's CPU and battery. If your phone has been powered off for a while, the reading is more accurate.

You can change the source and calibrate either one under Settings > Sensors > Thermometer (see the Settings user guide for the calibration steps). If you recorded temperatures with the sensor and then switched to historic, you can also update the previously recorded temperatures to the historic ones there.

Location and compass

The GPS isn't working or is inaccurate
  1. Ensure you have a clear view of the sky
  2. Open the Diagnostics tool to see if any GPS errors are detected. This will include a check for availability, permission, accuracy, and overrides.
  3. If you choose not to grant the location permission, set the GPS source to Manual and ensure the location override is properly set (Settings > Sensors > GPS > Location override).
  4. Check the accuracy filter (Settings > Sensors > GPS > Accuracy filter). It sets the accuracy Trail Sense prefers before accepting a reading, and how long it waits for it. If that accuracy isn't available in time, it uses the best recent reading, so try relaxing the preferred accuracy.
  5. Set GPS power usage to High accuracy (Settings > Sensors > GPS). With reduced power settings, some devices shut down the GPS while you are stationary, which can reduce the accuracy.
  6. Verify that high accuracy / precise location is enabled for Trail Sense. You can typically find this in your device's settings under location, privacy, or app settings.
Why is the GPS slower than other apps?

Trail Sense uses satellites (GPS and any other satellite system your phone supports) to determine your location. Unlike many other apps, it does not use network based location. Network location is fast in cities and suburbs, but it can be very inaccurate in the wilderness (and it needs the Internet to stay up to date), so I chose not to use it. The tradeoff is that it can take longer to get your first location, especially if you don't have a clear view of the sky or have GPS power usage set to something lower than High accuracy (Settings > Sensors > GPS). See the GPS question if it never gets a location.

The compass isn't working or is inaccurate
  • Try restarting your device
  • View the Diagnostics tool (Trail Sense Settings > Diagnostics) to see if it detects any issues. If your device is missing a magnetometer or accelerometer, the compass will be unavailable.
  • Recalibrate the compass. Settings > Sensors > Compass > Calibrate shows the compass accuracy, and if it is low you can tap it to see how to calibrate.
  • Adjust the compass smoothing under Settings > Sensors > Compass. Increase it if the compass is jittering, decrease it if it is slow to respond to real changes (a value of 1 is recommended when the source uses a gyroscope).
  • Try a different compass source under Settings > Sensors > Compass. On devices with a gyroscope, the default is "Magnetometer + Gyro (Custom)". If it doesn't work correctly, try "Magnetometer + Gyro", and if the gyroscope sources don't work well on your device, try "Magnetometer" or "Legacy (Trail Sense)".
  • If you are using True North, ensure your location is accurate (GPS settings) or the declination is correct. You can have it adjusted automatically ("Auto adjust declination") or enter your own with the declination override.
How do I hide the error banners at the top of a tool?

Some tools, such as Navigation and Astronomy, show a banner when something is wrong (ex. your device doesn't have a compass or the location permission is missing). If you don't want to see a banner, you can turn each one off under Settings > Errors.

The sunrise/sunset times are wrong

The astronomy tool needs to know your location to determine the correct times. Please see the FAQ for "The GPS isn't working or is inaccurate".

Notifications and background services

Trail Sense sends too many notifications
  • All notifications from Trail Sense can be disabled/re-enabled under their respective settings
  • Android requires background processes that access your location or use a sensor to send a notification (ex. Backtrack, weather monitor, and sunset alert). On most supported Android versions, you can disable the "Updates" notification channel to hide these notifications. (What are Android notification channels?)
  • The processes that you may see notifications from frequently are Weather, Sunset Alert, Backtrack, and Pedometer. All of these processes can be disabled in Trail Sense settings.
    • Weather: On the Weather tool, turn off Weather Monitor or hide the "Weather Monitor" notification channel (Android's settings)
    • Backtrack: On the Paths tool, turn off Backtrack or hide the "Backtrack" notification channel (Android's settings)
    • Pedometer: On the Pedometer tool, stop the Pedometer or disable the "Pedometer" notification channel (Android's settings)
    • Sunset Alert: Under Settings > Astronomy > Alerts in Trail Sense, disable Sunset (and Sunrise)
Backtrack, the weather monitor, or other background services stop running

Many phone manufacturers aggressively stop apps that run in the background. Things to try:

  1. Mark Trail Sense as exempt from battery optimizations (Trail Sense may ask you to do this the first time you start them): how to make Trail Sense exempt
  2. Turn off Trail Sense's power saving mode (Battery tool). It stops some services, such as Backtrack and the weather monitor, and they can't be started while it is on. If you have Automatic power saving turned on (Settings > Battery), it turns on by itself when your battery is low.
  3. Make sure notifications are enabled for Trail Sense. Android requires a notification for these services, so they may not run properly if the notification is blocked.
  4. On some devices, allowing location "all the time" for Trail Sense improves the reliability of backtrack and the weather monitor (it shouldn't be needed on most devices).
  5. Check the Diagnostics tool. It detects restricted background access, power saving mode being on, blocked notifications, and a missing background location permission.
My widgets aren't updating

Widgets update in the following situations:

  • About every 30 minutes (Android may delay this to save battery)
  • When you open Trail Sense
  • When their data changes (ex. a new weather prediction, the pedometer distance, or your location)

If a widget is out of date, check the following:

  • Location widgets (sun, moon, tides, map, nearby beacons, location, and elevation): These use your location, and Trail Sense can only refresh an out of date location in the background if it is allowed to access your location all the time (the background location permission).
  • Weather widgets (weather, pressure, and pressure chart): These show the latest pressure Trail Sense recorded, so they only update when a new reading is recorded. That happens automatically while the weather monitor is on, otherwise only when you open the Weather tool.
  • All widgets: Follow the steps for background services that stop running, since battery restrictions can stop the updates.
Sunset alerts or the clock are a few minutes off
  • Trail Sense needs the "Alarms & reminders" permission to post notifications at an exact time. Without it, the clock and sunset alerts can be off by several minutes. You can grant it in Android's app settings for Trail Sense, and the Diagnostics tool will tell you if it is missing.
  • Sunset alerts use your location. If you travel without opening Trail Sense, the times may be inaccurate unless Trail Sense is allowed to access your location in the background.
I can't turn off the flashlight/white noise or they won't turn on

Please verify your notification settings for Trail Sense by long pressing the Trail Sense app icon, then opening App Settings, then opening Notifications. Ensure that Trail Sense has notifications enabled and that the Flashlight and White Noise channels are active.

Flashlight notifications don't go away instantly when I turn it off

Unfortunately, Android requires that notifications are present for certain services for at least 5 seconds, there is no way to get around this as it is a system "feature". On newer versions of Android, this problem may be resolved.

Why are Trail Sense's notifications grouped on Android 16?

Unfortunately Google decided that all notifications are grouped on Android 16 and there is no way for Trail Sense to opt-out. See the issue for details.

Privacy and your data

Does Trail Sense use the Internet? Why does it need all these permissions?

No, Trail Sense doesn't have Internet access, and all of your data stays on your device. Each permission is only used by the tools that need it (ex. location for navigation and weather, camera for the sighting compass). You can deny any of them and the tools that depend on them will be limited or unavailable. For example, if you don't grant the location permission you can set your location manually under Settings > Sensors > GPS.

See the list of permissions for what each one is used for and what happens when it is denied, and the privacy policy.

How do I back up my data or move to a new phone?

Open Settings > Backup / restore. You can create a backup (a zip file with your data and settings), restore one, or turn on automatic backups, which save a backup every day at about 10 PM in a folder you choose (it keeps the last 2).

  • The backup is not encrypted and contains location data, so only share it with people you trust.
  • Restoring overwrites your current data and settings. You can restore a backup from an older version of Trail Sense, but not a newer one.
  • Trail maps (.map files) are only included if you turn on "Include trail maps in backups", since they can be large. The DEM is never included, so you will need to import it again.

Other

The tides are inaccurate

The tide tool is designed for you to enter tides from an official source. Do not rely on the estimated tides, as they may be inaccurate since tides are a very complex thing to predict without huge amounts of data.

Most estimated tides are accurate to within an hour.

Why does the sensor quality say "Unknown"?

Some devices don't report sensor quality (more common with barometer / thermometer) and therefore Trail Sense shows "Unknown" rather than "Poor/Moderate/Good/Unavailable". If you are receiving a value from the sensor and it appears to be sufficiently accurate then you do not need to worry about having "Unknown" there.

Translations are missing or incorrect

Translations for Trail Sense are community sourced through Weblate, and I am unable to verify their accuracy (other than English and a very small amount of Spanish). Please use Weblate to add or fix translations. Alternatively, you can create an issue on GitHub or email me at trailsense@protonmail.com to provide the missing or corrected translation - or tell me to remove a translation so it can be re-translated by the community.

Use the following filter on Weblate to see which strings are in need of translation: state:<translated
