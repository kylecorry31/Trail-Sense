This contains a list of the changes in Trail Sense 0.8.0.

- Manual overrides for location, altitude, and declination
- Improved GPS accuracy
- Calibration reminder
- Pressure tendency display (in tab and notification)
- Ability to force pressure readings at a set interval
- Experimental features: inclinometer and tidal range (enable in settings)
- About section in settings
- Bug fixes
