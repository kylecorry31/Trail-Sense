This contains a list of the changes in Trail Sense 2.3.0.

- Turn on flashlight with volume key (off by default)
- New settings organization
- Custom backtrack record duration
- Improve water depth calculation
- Metal detector direction (experimental, requires gyroscope)
- Map improvements (experimental)
- Bug fixes
