This contains a list of the changes in Trail Sense 2.5.0.

- "Inventory" was revamped into "Packing Lists"
- Create packing lists to prepare for hiking trips
- Keep track of pack weight
- More item categories
- More colors for beacons
- Add USNG and OSNG coordinate formats
