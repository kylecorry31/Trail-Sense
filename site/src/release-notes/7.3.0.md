This contains a list of the changes in Trail Sense 7.3.0.

- Tap beacon name to open it while navigating

## Ballistics

- Add ballistics calculations (drop, velocity)

## Weather

## Misc

- Add tool shortcuts to homescreen
- Add widget theme customization
