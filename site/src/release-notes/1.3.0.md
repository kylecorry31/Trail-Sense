This contains a list of the changes in Trail Sense 1.3.0.

- Add flashlight to tools (SOS only available in there now)
- Add Solar Panel Aligner tool
- Add Water Boil Timer tool
- Add sensor details display in About Settings
- Bug fixes

## Known Issues

- Clicking to turn off strobe or SOS can sometimes cause the regular flashlight to turn on
