This contains a list of the changes in Trail Sense 4.7.0.

## Weather

- Show more information on weather tab (weather front, pressure system, last cloud)
- Show time of day on pressure chart
- Set the date/time of cloud readings
- Improve sea level calibrator v2 when changing location (experimental)
- Show raw sea level readings while calibrating barometer
