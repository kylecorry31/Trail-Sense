This contains a list of the changes in Trail Sense 2.7.0.

- Add temperature estimation at different altitudes (available through thermometer tool)
- Add diagnostic tool to settings
- Choose which beacons to import
- Long press astronomy calendar icon to search for events
- Improved distance entry
- Bug fixes
