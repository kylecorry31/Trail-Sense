This contains a list of the changes in Trail Sense 3.0.0.

- Path customization: name, color, style, simplify, merge, hide/show
- Path details: map, elevation gain/loss, duration, distance, difficulty
- Import paths from GPX
- Backtrack tool renamed to Paths
- Improved path loading on radar compass
- Improved barometer calibration
