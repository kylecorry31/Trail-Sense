This contains a list of the changes in Trail Sense 1.0.0.

- Beacon groups
- 2D bubble level
- Improved sea level pressure calculations (tuning available in barometer calibration settings)
- Improved background weather monitoring
- User guide (more coming soon!)
- Clicking on sun/moon shows altitude
- Bug fixes
